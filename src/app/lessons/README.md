# Структура навчальних завдань

- `/` — головна сторінка з каталогом (`pages/lesson-catalog`).
- `/lessons/component-inputs` — передача даних у картку товару.
- `/lessons/profile-editor` — редактор профілю.
- `/profile-lab` — сумісне перенаправлення на редактор профілю.

`App` містить лише `router-outlet`. Кожен урок має власну папку та компоненти.
Уроки завантажуються через `loadComponent` при переході за адресою.

## Як додати наступний урок

1. Створи компонент Angular CLI в новій тематичній папці `lessons/`.
2. Додай запис до `lesson-registry.ts`: унікальний `path` без `/`, номер,
   назву, опис, теми, тему оформлення (`sage` або `violet`) і `loadComponent`.
3. Картка каталогу та маршрут `/lessons/<path>` створяться з цього запису.
   Дублювати записи в `app.routes.ts` чи HTML каталогу не потрібно.
4. У шаблоні уроку додай посилання `routerLink="/"` до каталогу.
5. Перевір `npm run build` та `npm test -- --watch=false`.

Каталог не зберігає прогрес і не визначає, чи виконаний урок.
